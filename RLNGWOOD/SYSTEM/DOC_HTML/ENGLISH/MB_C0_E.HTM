mbedit - Multi Platform Editor

mbedit is a full screen text editor with macro option, online calculator, command history buffer, hex editor and many other features.
It is available for some common operating systems as: MS-DOS, os/9, unix.
The program package is written in ANSI-c and is easy to port to different platforms:

operating systems

  • Microsoft
    • MS-DOS
    • Windows 95, 98, NT, 2000, XP
    • CYGWIN (Unix for Windows)
  • OS-9
    • OS-9 68k (Microware)
    • OS-9000 (Power PC)
  • unix
    • Motorola System V Rel. 4
    • DEC ultrix
    • Silicon Graphics IRIX
    • sun os (GNU c-Compiler)
    • SCO-Unix
    • linux
    • OSF/1
    • QNX 4/6
    • hp-ux

  • VGA
  • VT100

keyboard input
