4. Aufruf-Syntax 


- Der Aufruf von mbedit hat folgende Syntax:
       
   mbedit [filenames] [options]

    - Die Reihenfolge von [filenames] und [options] ist so vorgeschrieben.

    - [filenames]: [<filename 1>] [<filename 2>] ... [<filename n>]

      Mit mbedit ist man in der Lage, mehrere Files gleichzeitig zu editieren.
      Die obere Grenze ist z.Z. willkürlich auf 26 festgelegt.

      Die Anzahl der editierbaren Files ist normalerweise 2, kann aber per
      Kommando verändert werden (1 bis 26). Bei Angabe von n Filenamen in der
      Kommandozeile wird automatisch auch die Zahl der Files auf n gesetzt.

      Der Editor kann auch ohne Angabe eines Filenamens aufgerufen werden,
      z.B. zur Benutzung des Taschenrechners.

    - [options]  : [- | last_again] [vo | viewonly] [batch]
                   [nomacro] [macro(<macrofile>)]

       - - | last_again: Die gleiche File-Zusammenstellung wie bei der letzten
                         Editier-Sitzung wird aufgerufen. Sogar der Cursor
                         ist an der gleichen Position.

       - vo | viewonly:  Der File darf nur gelesen, aber nicht modifiziert 
                         werden. Hiermit kann man sich gegen versehentliche
                         Änderungen schützen.

       - batch:          Die Kommandos für mbedit können statt von der Tastatur
                         auch - per Eingabeumleitung - aus einem Datenfile 
                         kommen. In diesem Fall kann es sinnvoll sein, die
                         Anzeige mit option "batch" zu unterdrücken. Die
                         Kommandos laufen dann schneller ab.

       - nomacro:        mbedit sucht standardmäßig nach dem Macro-File
                         "MBEDIT.MAC". Mit dieser option kann das Einlesen
                         des Macro-Files unterdrückt werden (siehe auch die
                         Kapitel "Macros" und "Macro-File").

       - macro(<macrofile>):  Hiermit kann mbedit angewiesen werden, einen
                         anderen Macro-File anstelle des Default-Macro-File
                         "MBEDIT.MAC" einzulesen. In dieser Option dürfen vor
                         und zwischen den Klammern keine Leerzeichen stehen.


- Wird mbedit mit einer der Options "-?", "-h" oder "-help" aufgerufen,
  erscheint eine kurze Hilfsanzeige zur Aufruf-Syntax.
