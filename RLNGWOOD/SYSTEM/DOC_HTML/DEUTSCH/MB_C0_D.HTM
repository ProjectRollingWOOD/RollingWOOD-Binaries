mbedit - Multi Platform Editor

mbedit ist ein Bildschirm-Text-Editor mit Macro Option, Online Calculator, Command History Buffer, Hex-Editor und vielen anderen Möglichkeiten.
Er ist verfügbar für einige gebräuchliche Betriebssysteme wie: MS-DOS, os/9, unix.
Das Programm-Paket ist in ANSI-c geschrieben und leicht auf verschiedene Umgebungen portierbar:

Betriebssysteme

  • Microsoft
    • MS-DOS
    • Windows 95, 98, NT, 2000, XP
    • CYGWIN (Unix for Windows)
  • OS-9
    • OS-9 68k (Microware)
    • OS-9000 (Power PC)
  • unix
    • Motorola System V Rel. 4
    • DEC ultrix
    • Silicon Graphics IRIX
    • sun os (GNU c-Compiler)
    • SCO-Unix
    • linux
    • OSF/1
    • QNX 4/6
    • hp-ux

Bildschirm-Ausgabe

  • VGA
  • VT100

Tastatur-Eingabe

  • PC-MF2
  • VT220
