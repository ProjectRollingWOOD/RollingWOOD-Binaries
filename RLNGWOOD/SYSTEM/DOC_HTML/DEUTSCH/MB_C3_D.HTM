3. Express-Bedienungs-Anleitung 

 

Wer sofort mit mbedit arbeiten will, muß nicht die ganze Bedienungsanleitung
studieren. Zum basisartigen Arbeiten genügen einige wenige Kommandos. 

Nur zum Gebrauch eines besonderen Features (z.B. Macros) sollten die
Hinweise in dem jeweiligen Kapitel beachtet werden.

Hier die wichtigsten Kommandos in Kurzform auf einer Seite:

Aufruf:     mbedit <filename>

Editieren:  mbedit unterscheidet 3 Modi: Command, Insert und Exchange.

            Zum Eingeben eines Textes wechselt man vom Command- in den
            Insert- oder Exchange-Mode (Eingabe von 'I' bzw. 'X').

            Insert: Die eingegebenen Zeichen werden an der Cursor-Position in
            den Text eingefügt.

            Exchange: bei Eingabe neuer Zeichen wird der alte Text an der
            Cursor-Position überschrieben.

            Mit <esc> kommt man zurück in den Command-Mode.

Cursor-Tasten: Zum Positionieren des Cursors innerhalb des Textes
            (in allen 3 Modi).

Beenden:    Im Command-Mode 'Q' und 'E' eingeben (für Quit Exit).
            Der editierte File wird zurückgeschrieben und mbedit verlassen.

Abbrechen:  Im Command-Mode 'Q' und 'A' eingeben (für Quit Abort). Wenn der
            aufgerufene File modifiziert wurde, gibt mbedit eine Warnung
            aus: "modified: abort anyway ? [Y/N/W]", die quittiert werden muß.

            'Y' = Yes   : Abbruch ohne Update, die Änderungen gehen verloren.
            'N' = No    : kein Abbruch, Verbleiben in mbedit.
            'W' = Write : File schreiben und mbedit beenden (wie Quit Exit).
