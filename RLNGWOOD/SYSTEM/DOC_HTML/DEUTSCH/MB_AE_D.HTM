Anhang

E. Konfiguration des Syntax Highlighting 


Dies ist eine neue Möglichkeit, das Syntax Highlighting entsprechend
der Programmiersprache / Filetypen zu konfigurieren.

Der Konfigurations-ASCII-File "mbedit.sys" (normalerweise auf dem gleichen
Verzeichnis angesiedelt wie der Macro-File "mbedit.mac") enthält
Steuer-Informationen über die gewünschten File-Extensions,
den/die Kommentar-Character und die reservierten Wörter.

Eine Kurzübersicht über den Pfadnamen des Konfig-Files und die
geladenen File-Typen erhält man mit dem Kommando ML ('M'acro 'L'ist).

Die Einstellung des aktuellen Files wird ebenfalls angezeigt im <F1>
Hilfemenü, in der Form:

sYntax hl [7,2], wobei die zwei Parameter folgende Bedeutung haben:
           | |
           | +-- file_type (z.B.: 1="c", 2="cpp" "h", ...)
           +-- highlight status (Bit-Kombination von:
                                 1=comments, 2=keywords, 4=strings)

Wenn die Extension des aktuellen Files nicht in der Liste gefunden wird,
wird der Status auf 0 voreingestellt (Highlighting "Aus"). Wenn die
Extension bekannt ist, wird er auf 7 gesetzt, und der Filetyp entsprechend
der Extension eingestellt.

Die aktuelle Einstellung der zwei Parameter kann geändert werden:
Mit dem Kommando SY ('S'et s'Y'ntax) und 1 oder 2 folgenden Zahlen,
durch ein Komma getrennt, z.B.: SY 7,1

Ein Beispiel des Konfigurations-Files befindet sich hier:
mbedit.syn !

Es kann einfach an neue Anforderungen angepasst und erweitert werden
(andere Programmiersprachen oder Filetypen).

Unterstützte Sprachen / Datei-Typen (bisher...)

siehe Extra-File syntax.htm !
