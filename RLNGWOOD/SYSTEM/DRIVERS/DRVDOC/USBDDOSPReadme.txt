To use USBDDOSP.EXE, first start HDPMI, using "HDPMI32i -r"
then launch USBDDOSP.EXE

Available options:
/RW: Enable RetroWave OPL3 supprt. EMM386 v4.46+ needed.
/disk: Enable USB-disk support.
/HID: Enable USB keyboard & mouse support.
options are not case sensitive.

To work with a USB mouse, you also need CuteMouse.

command line example:
HDPMI32i -r
USBDDOSP
CTMOUSE
